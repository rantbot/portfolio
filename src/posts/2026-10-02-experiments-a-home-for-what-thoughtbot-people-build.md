I created Space Station to organize work between client engagements, along with an experiment framework to help people turn ideas into tangible work and shared learning. Experiments is where that work lives.

It’s a public catalog where people at thoughtbot share the tools they’ve built. Teammates can see what’s new, understand what an experiment does, try it, leave quick feedback, and vote on whether it’s ready for production. The people who built it can see how it’s being used.

I kept it deliberately small. There’s no admin screen and no content system. Each experiment is a single file in a Git repository, so adding one is as simple as committing it.

[See the experiments](https://thoughtbot.github.io/experiments/)
